### 📌 Projetos em Destaque

#### 🤖 [RendaIA](#)
> Assistente inteligente desenvolvido para o Desafio X (UniCatólica) que orienta populações vulneráveis sobre programas sociais (como Bolsa Família e CadÚnico), cursos gratuitos e vagas de emprego em linguagem simples, via web e integração com WhatsApp[cite: 1, 2].
* **Tecnologias:** Python, Node.js, React.js, LLM com RAG, PostgreSQL, Redis, WhatsApp API[cite: 1, 2].
* **Impacto:** Redução do tempo de busca por programas sociais de horas para minutos, com custo por consulta próximo de zero[cite: 2].

* **Tecnologias:** HTML5, CSS3, Tailwind CSS, JavaScript, Design Responsivo.
